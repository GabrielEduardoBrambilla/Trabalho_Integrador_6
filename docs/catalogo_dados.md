# Catálogo de dados — `dados/gold/pnad_treated_data.csv` (principal)

Dataset final **principal** do PM3 — gap salarial — gerado por `notebooks/03_tratamento_pm3.ipynb` (seção 16) a partir do silver `dados/silver/pnad_limpo.csv`. **384 linhas × 15 colunas**. Cada linha representa um indicador de força de trabalho, informalidade ou rendimento (tabelas SIDRA 4093 e 5436) para uma combinação de UF, sexo e trimestre. Não inclui a tabela 7322 (nível de instrução) — ver `catalogo_dados_contexto.md`.

## Observações gerais

- **Por que não tem `regiao_nome`/`nivel_instrucao`:** este arquivo só contém as tabelas 4093/5436 (nível UF, sem nível de instrução) — essas colunas seriam sempre `"Não se aplica"`, então foram removidas na consolidação (seção 16 do notebook). Quem precisar de nível de instrução por sexo deve usar `dados/gold/pnad_context_data.csv` (ver `docs/catalogo_dados_contexto.md`).
- **Lacuna temporal:** a tabela 5436 não possui dados para 2020T2–2022T1 (Problema 9); consequentemente `gap_salarial_pct` também não existe para esse intervalo — as 96 linhas com `gap_salarial_pct` nulo são todas da tabela 4093, nos 8 trimestres em que 5436 não tem dado para fazer o pivot de sexo (as demais 192 linhas de 4093 herdam o `gap_salarial_pct` calculado a partir de 5436 para o mesmo UF/trimestre).
- Nenhum outlier foi detectado pelo IQR neste dataset (4093/5436) — ver seção 12 do relatório final.

### **Projeto Mensal 4 - (** _Entrega do trabalho peso 40% e Apresentação peso 60%_ **)**

### 1. Apresentação

Neste Projeto Mensal 4, você deverá utilizar a base de dados tratada no PM3 para criar visualizações, interpretar informações e construir um dashboard simples.

No PM3, o foco foi preparar os dados. Agora, o foco será transformar esses dados em gráficos, indicadores e análises visuais que ajudem na tomada de decisão. O PM3 já exigia a entrega de um dataset final tratado, pronto para uso em BI, Data Mining ou análise exploratória .

O objetivo não é criar muitos gráficos, mas sim criar boas visualizações. Um gráfico precisa responder uma pergunta. Se não responde nada, é só enfeite.

### 2. Objetivo geral

Construir visualizações de dados e um dashboard simples a partir de uma base real tratada, aplicando princípios básicos de análise visual e Business Intelligence.

### 3. Base de dados

Utilize, preferencialmente, a mesma base tratada no PM3.

A base deverá permitir:

Análise por categorias.

Análise de valores numéricos.

Criação de indicadores.

Construção de gráficos.

Criação de filtros no dashboard.

### 4. Etapas do projeto

### Etapa 1 — Briefing da visualização

Antes de criar os gráficos, organize o objetivo da análise.

Responda:

Qual é o tema da base?

Qual problema essa base ajuda a entender?

Quem poderia usar essas informações para tomar decisão?

Quais perguntas serão respondidas com os gráficos?

Quais indicadores serão utilizados?

Apresente pelo menos **3 perguntas analíticas** .

Exemplos:

Qual categoria possui maior quantidade de registros?

Existe crescimento ou queda ao longo do tempo?

Quais grupos apresentam melhor ou pior desempenho?

Quais valores estão acima ou abaixo da média?

Existe concentração de resultados em poucas categorias?

### Etapa 2 — Planejamento dos gráficos

Escolha os gráficos que serão utilizados no projeto.

Apresente pelo menos **4 gráficos planejados** .

Para cada gráfico, informe:

Título do gráfico.

Tipo de gráfico.

Colunas utilizadas.

Pergunta que o gráfico responde.

Justificativa da escolha.

Exemplos de gráficos permitidos:

Gráfico de barras.

Gráfico de colunas.

Gráfico de linha.

Gráfico de pizza ou rosca, quando fizer sentido.

Histograma.

Boxplot.

Mapa de calor.

Gráfico de dispersão.

Tabela ou ranking.

### Etapa 3 — Construção das visualizações

Construa pelo menos **4 visualizações finais** .

Cada visualização deverá conter:

Título claro.

Dados corretos.

Eixos ou legendas identificados.

Boa organização visual.

Interpretação do resultado.

Não basta colar o gráfico no relatório. Explique o que ele mostra.

Exemplo de interpretação:

“O gráfico mostra que a categoria X concentra a maior parte dos registros. Isso indica que essa categoria tem maior peso na análise e deve receber mais atenção na tomada de decisão.”

### Etapa 4 — Dashboard final

Construa um dashboard simples com os principais resultados da análise.

O dashboard deverá conter:

Pelo menos **3 indicadores principais** .

Pelo menos **4 gráficos** .

Pelo menos **1 filtro interativo** .

Título do dashboard.

Fonte dos dados.

Organização visual clara.

Exemplos de indicadores:

Total de registros.

Média geral.

Valor total.

Maior valor.

Menor valor.

Quantidade por categoria.

Percentual de participação.

Evolução por período.

### 5. Entregáveis obrigatórios

Ao final do PM4, entregue:

1. Base utilizada no projeto.
2. Briefing da visualização.
3. Pelo menos 3 perguntas analíticas.
4. Planejamento de pelo menos 4 gráficos.
5. Pelo menos 4 visualizações finais com interpretação.
6. Dashboard final.
7. Prints ou link do dashboard.
8. Relatório final.

### 6. Estrutura sugerida do relatório

O relatório final deverá conter:

1. Introdução.
2. Tema da base.
3. Fonte dos dados.
4. Relação com o PM3.
5. Objetivo da análise.
6. Perguntas analíticas.
7. Indicadores utilizados.
8. Gráficos planejados.
9. Visualizações construídas.
10. Interpretação dos resultados.
11. Descrição do dashboard.
12. Conclusão.
